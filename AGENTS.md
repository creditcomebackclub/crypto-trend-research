# Repository instructions

For every future research task in this repository, commit and push the preregistration to GitHub as a separate push **before** running any analysis on real data. Do not combine preregistration with implementation or results in one push. Synthetic-data development and tests may run before that push; real-data analysis may not.

Keep all work, commands, generated artifacts, and external actions scoped to this repository. Do not deploy this repository or run its code from another project or service.
